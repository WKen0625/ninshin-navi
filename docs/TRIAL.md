## 3. 見てもらうこと（5〜10分）

1. 入口: 市区町村・予定日・手元の紙を入れる → 迷った項目は？ 自分の持っている紙は一覧にあったか？
2. 次にやること: いちばん上の Next Action は、いま本当にやるべきことだったか？ もう済んだことが出ていないか？
3. 病院と締切: 自分が検討した施設があるか。締切の目安は、実際に言われた内容と合っているか？
4. お金: 施設を選んで出た「実際の負担の目安」は、感覚と合うか？ 知らなかった助成はあったか？
5. 言葉: 大学生でもわかる言葉になっているか（CLAUDE.md §6）

## 4. 集まったものの見方（運営者）

| 見るもの | コマンド |
|---|---|
| まちがいの知らせ・一覧にない紙 | `pnpm feedback:list`（対応したら `--done <番号>`） |
| 出典ページの変更 | `pnpm watch:report` |
| 分娩予約の記録の件数 | Supabase の `v_booking_stats`（画面の「病院と締切」にも出る） |

## 7. わかっている限界（試用の前に伝えておくとよいこと）

- メールでのお知らせは、まだ無い（準備中）

- 入力は端末の中だけ。機種変更やブラウザのデータ削除で消える（引き継ぎ機能は無い）
- 施設の予約ルールは半分が未確認で、「電話で確認」と出る
- 無痛分娩の費用そのものは、計算に入っていない
- 新しい制度（分娩費用の保険適用）は、金額が未定のため計算しない
- PDFの出典と、e-Gov の条文ページは、変更監視で中身の変化に気づけない
