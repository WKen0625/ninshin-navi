- 妊婦面談で**もらえる品物**の有無（ページ本文に記載なし。「妊娠届出時の面談について」というPDF（3.4MB）はテキストを取り出せず未確認）。タクシー利用券は面談とは別に申請する形で書かれている。
- 妊婦健康診査受診票の1回ごとの助成額（受診票のページには無し。里帰りのページの表だけ）

- 妊娠高血圧症候群等医療費助成の申請窓口・期限（ページに明記なし。「遅延証明書（申請日が退院日以降の場合）」とあるだけ）
- 多胎児を妊娠した人への妊婦健診費用助成（ページがあるが今回は読んでいない。未収録）

## あいまいで、人に確認してほしい点

1. 1か月児健診のページに「都内契約医療機関の受付に「**産婦健康診査受診票**」を提出し」と書いてある。区の書き間違いと思われる（受診票の交付の段では「1か月児健康診査受診票」）。YAMLでは「受診票」とだけ書いた。
2. `chuo.s07d`（新生児誕生祝品）は現金でないので subsidies に入れず、ステップにした。期限「1歳になる前日まで」は日数にせず `deadline_note` だけにした。追加支援2万円分は期間限定の可能性がある。
3. `chuo.s05b` の `deadline_week: 28` は「妊娠8か月頃」を世田谷区の書き方（28週）にならって置いた値。区のページに週数の記載はない。
4. `chuo.s07c` の `deadline_base: birth_date +365` は妊婦健診分の期限。新生児聴覚検査・1か月児健診は「受診した日から1年以内」で基準日が違う（`deadline_note` に併記）。
5. マイナポータルで届け出た場合に受け取れない場所は、原文が「中央区役所・日本橋及び月島特別出張所」（晴海には触れていない）。YAMLも原文どおりに書いた。晴海特別出張所の扱いは要確認。
