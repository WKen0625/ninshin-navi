## アフィリエイトの観点で見た「稼げる順」の見立て

1. **サービス系（成果報酬が高い）**: 食材宅配（生協・Oisix）、ウォーターサーバー、学資保険の資料請求、ベビーカー・ベビーベッドのレンタル。1件数千円。A8.net／バリューコマース／もしもアフィリエイト。
2. **高単価の物**: ベビーカー、チャイルドシート、抱っこひも、ベビーベッド、電動鼻水吸引器、ドラム式洗濯機・食洗機。Amazon（ベビー・マタニティは料率が低め）より楽天・Yahoo!の方が料率が高いことがある。
3. **継続購入の消耗品**: おむつ、おしりふき、ミルク、母乳パッド、ノンカフェイン飲料。単価は低いが定期購入のリンクで積み上がる。
4. **信頼づくり用（安いが読まれる）**: 入院バッグの小物、ストローキャップ、産褥ショーツ。

「セット売り（リンクのまとめ）」の候補: ①入院バッグ一式（陣痛／入院／退院の3袋）、②新生児の最初の1か月セット（肌着・おむつ・保湿・哺乳びん・消毒）、③産後の回復セット（骨盤ベルト・母乳パッド・乳頭ケア・産褥ショーツ）。

## 次にやること

1. Amazon アソシエイト・楽天アフィリエイト・A8.net（サービス系）の登録（Kenさん）。
2. 上の表の商品を、Kenさんのアカウントで Amazon／楽天のランキングと突き合わせ、実際に売れているものに絞る（ここは自動化できないので手作業。1品目5分）。
3. コラム10「産前に買う／産後でよい」、13「入院バッグ」、16「最初の1か月」に、この表から選んでリンクを入れる。
4. Naviの `products_used` アンケート（使ってよかった物を3つまで）の選択肢を、この表の品目に合わせて整える → 利用者の記録で「本当に使われた物」の順位が溜まる。
