## 公式ページと既存データの食い違い（データは変えていない）
- 健康推進課の所在地: 組織ページは「豊島区保健所3階」、妊娠届ページは「保健所2階 総合窓口」。妊娠届などの受付は2階総合窓口なので contacts の address は2階とし、課の所在地3階を併記した。
- s06d の detail は「区役所3階9番の国民健康保険課」で、減額ページと一致。第2土曜の休日窓口でも産前産後の減額申請は受け付ける（休日窓口ページ 006902）。
- 出生届ページには「豊島区に住所のある人は子どもの住民登録が必要なので平日15時まで・土曜14時まで」とあり、既存 steps（jp.s07 出生届の共通行）にはこの注意が無い。contacts の note に入れた。
