## 見つからなかった項目

- **区独自の出産費用助成・出産祝い金**: 区のサイトを検索したが見つからない。あるのは「出産費用の助成（入院助産）」（生活保護・非課税世帯向け）だけ。→ 入れていない。
- **妊婦支援給付金の申請期限**: ページ本文に記載なし。FAQ の PDF（/documents/1125/r70401_faq_ninpusienkyuuhukinn.pdf）は読めなかった。→ 「記載なし」と書いた。
- **妊婦健診受診票の枚数（14回・超音波4回・子宮頸がん1回）と各回の上限額**: 本文にははっきり書かれていない（「14回分」は多胎の説明に、「4枚未満」は転入の説明に出てくるだけ）。→ 数字は断定せず、その旨を description に書いた。
- **都外受診の払い戻しの上限額**: 「上限金額は申請書をご確認ください」とあり、申請書 PDF は読めていない。
- **ゆりかご券の金額**: 面接のページに金額なし（子育て応援券のページは未確認）。

## あいまいで、人に確認してほしい点

- s08e の期限を `birth_date + 364日`（1歳の誕生日の前日）とした。港区・世田谷区の「1年以内 = 365」とは1日ちがう。
- s08b は、令和8年9月30日までと10月1日以降で仕組みが変わる（9月までは区内の指定機関・申込書は機関にある）。10月以降は古い説明を消してよい。
- 1109.html の URL は検索結果では /guide/kosodate/ninshin/… の形でも出るが、ページID にそろえて /s054/… を出典にした。
