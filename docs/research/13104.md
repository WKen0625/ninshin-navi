## あいまいで、人に確認してほしい点

1. 国保のページの電話番号は「5273-4146」と市外局番なしで書かれている。YAMLには原文の表記のまま入れた（03 を足すかどうかは人が判断）。
2. `shinjuku.s03` の `deadline_week: 11` は「できれば11週までに」というおすすめで、期限ではない。
3. `shinjuku.s05b` の `deadline_week: 24` は「妊娠7か月頃」を24週と置いた値。区のページに週数の記載はない。
4. `shinjuku.hoken_bag` の `includes` に歯科と新生児聴覚の受診票を入れたが、区の書き方は「母子手帳と同時に交付」「妊娠届出時に窓口で交付」で、バッグの中とは明記していない（産婦・1か月児は「バッグに同封」と明記）。
5. 妊娠届と妊娠高血圧のページは最終更新日が古い（2024年12月、2022年4月）。内容がいまも有効か確認してほしい。
6. 支援給付は「5万円相当」（現金か電子ギフトを選ぶ）。`kind: cash_later`・`amount_yen: 50000` とし、電子ギフトも選べることを `amount_note` に書いた。
