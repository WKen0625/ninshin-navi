## あいまいで、人に確認してほしい点

1. `chiyoda.hoken_bag` の `includes` に新生児聴覚・産婦・1か月児の受診票を入れたが、区のページは「妊娠届の提出時に配付」「受診票と合わせてお渡しします」という書き方で、「バッグの中に入っている」とは明記していない。
2. `chiyoda.shussanhi` の計算式は `min(cost - lumpsum, 310000)`。付加給付・高額療養費・都の無痛分娩助成を引く部分は式に入れられないので `amount_note` に書いた。`amount_is_upper_limit: true` を付けた。
3. 支援給付の案内は紙で渡されるのか口頭なのか不明（「申請方法をご案内します」）。documents に「案内」として入れた。
4. 乳児家庭訪問の出生通知票は「母子健康手帳にとじ込まれている」ため、独立した document にせず、ステップの trigger を `chiyoda.hoken_bag` にした。
