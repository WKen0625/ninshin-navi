# 負担軽減コラムの計画: 周期ごとの課題と、コラムの候補

作成: 2026-09-23。コラム（content/articles）を書く前に、妊婦さんと家族が周期ごとに何に困るかを洗い出したもの。
書けること・書けないことの線は `docs/ARTICLES.md`（医療の判断は書かない。制度の数字には出典。製品は PR 表記）。

課題は5つの種類に分けている。
**手続き**（役所・保険）／**お金**（費用・助成）／**病院**（予約・受診）／**準備・買い物**（コラムでアフィリエイトにつながる）／**仕事**（産休・育休・職場）。
「体調」は課題として書くが、コラムでは「産院に相談する」で止める。

各コラムの候補には、周期（stage）・PR（製品を載せるか）・出典の当てを付けた。Naviの手続き（steps）と重なる話は、コラムでは「考え方」だけを書き、答えは Navi の画面に任せる。

---

## 妊娠初期（〜15週）`early`

いちばん情報が無く、いちばん急ぐ時期。判明から数週間で「病院を決める」「届を出す」が重なる。

| 種類 | 課題 |
|---|---|
| 病院 | 分娩施設の予約が早い（都心は心拍確認直後に埋まる施設がある）。「いつ・どこに・何を聞いて電話するか」がわからない。無痛分娩の可否・24時間対応・費用が施設で大きく違う |
| 手続き | 妊娠届をいつ出すか（心拍確認後）。母子手帳と受診票の使い方。区の面接を受けないと支援給付が受けられない区がある |
| お金 | 妊娠が確定するまでの受診は自費。健診の受診票でどこまで無料か。支援給付の1回目（5万円）の受け取り方 |
| 仕事 | 職場にいつ言うか。母性健康管理指導事項連絡カード（つわり等で勤務の配慮を求める紙）。通勤緩和 |
| 準備・買い物 | 買うものはまだ少ない。葉酸などは医療の話になるので書かない |
| 体調 | つわりで役所に行けない → 郵送・電子申請・代理の可否（区ごと） |

コラムの候補
1. **妊娠がわかった日から2週間でやること（順番と理由）** — early／PR なし／出典: 各区の妊娠届ページ・厚労省
2. **分娩予約の電話で聞くこと10項目（無痛・費用・締切・里帰り）** — early／PR なし／出典: 出産なび・施設HP。Naviの「電話した結果を記録」につなげる
3. **つわりで動けないときの手続き: 郵送・電子申請・代理でできること** — early／PR なし／出典: 各区のページ（区ごとの違いは Navi に任せ、コラムは「調べ方」）
4. **職場に伝えるタイミングと「母健連絡カード」の使い方** — early／PR なし／出典: 厚労省「母性健康管理」
5. **妊娠初期に「買わなくていいもの」リスト** — early／PR あり（買うものが少ない時期なので、売るより信頼づくり）

## 妊娠中期（16〜27週）`mid`

体調が落ち着き、決めごとが増える。里帰りか否か、無痛か否か、仕事をいつまで続けるか。

| 種類 | 課題 |
|---|---|
| 病院 | 里帰り出産の段取り（紹介状、転院の時期、受診票が県外で使えない→払い戻し）。無痛分娩の申込み締切（施設により30週など） |
| 手続き | 区の面接・歯科健診・8か月アンケート（区ごとに名前が違い、見落とす）。出産育児一時金の直接支払制度の書類 |
| お金 | 出産費用の見積もり（費用−一時金−助成）。無痛の追加費用。都の無痛助成の条件（対象施設） |
| 仕事 | 産休の開始日の計算（予定日の6週間前）。育休の取り方（父親の産後パパ育休を含む）。会社への書類 |
| 準備・買い物 | 両親学級。マタニティ用品（腹帯・下着・服）。抱っこひも・ベビーカー・チャイルドシートは「産後すぐ要る/要らない」の見極めが難しい |
| 保険 | 民間の医療保険は妊娠中に入りにくい（帝王切開の給付）。ここは断定しない |

コラムの候補
6. **里帰り出産の段取り表（いつ何を、どの区に頼むか）** — mid／PR なし／出典: 各区「里帰り等妊婦健診助成」・施設HP
7. **産休はいつから？ 予定日から逆算する計算と、会社に出す紙** — mid／PR なし／出典: 厚労省・協会けんぽ・日本年金機構
8. **産後パパ育休を含む、育休の組み方3パターン** — mid／PR なし／出典: 厚労省
9. **出産費用の目安の読み方（出産なびの中央値と、実際の請求の差）** — mid／PR なし／出典: 出産なび。Navi「お金」へつなげる
10. **ベビー用品「産前に買う／産後でよい」の分け方** — mid／PR あり（Amazon）／出典なしでよい（考え方）
11. **チャイルドシートは退院の日に要る（選び方と、区の貸出・助成）** — mid／PR あり／出典: 警察庁・各区の貸出制度（ある区だけ）

## 妊娠後期（28週〜）`late`

入院の準備と、出産直後の手続きの「予習」。ここで準備しないと産後2週間の期限に追われる。

| 種類 | 課題 |
|---|---|
| 手続き | 出生届（14日）・児童手当（15日）・健康保険の加入・出生通知票 … が産後2週間に集中する。名前の決め方（使える漢字）。父親が動けるように事前に書類を揃える |
| お金 | 分娩予約金・入院時の持ち込み金額。限度額適用認定証（帝王切開など保険診療になったとき）。医療費控除の領収書の残し方 |
| 病院 | 入院バッグ（産院のリスト）。陣痛時の移動手段（タクシー登録）。上の子の預け先 |
| 仕事 | 産休の手続き（出産手当金）。育休の申出（1か月前まで） |
| 準備・買い物 | 入院バッグの中身、退院時の赤ちゃんの服、新生児のおむつ・肌着・寝る場所。ここが買い物の山 |

コラムの候補
12. **産後2週間の手続きを、出産前に父親と分担する表（誰が・どこへ・何を持って）** — late／PR なし／出典: 戸籍法・各区のページ。Naviの「窓口の分別」を紹介
13. **入院バッグの中身は、産院のリストから始める**（公開済み `hospital-bag`）— late／PR あり（Amazon のリンクを足す）
14. **陣痛タクシーと、上の子の預け先を28週までに決める** — late／PR なし／出典: 各タクシー会社・各区の一時保育
15. **帝王切開になったときの費用: 限度額適用認定証と民間保険の確認** — late／PR なし／出典: 協会けんぽ・厚労省（医療の判断はしない。費用の話だけ）
16. **新生児の寝る場所と、最初の1か月に本当に使うもの** — late／PR あり／出典: 消費者庁（寝具の安全）
17. **医療費控除のために、いまから領収書を残す** — late／PR なし／出典: 国税庁

## 出産・入院 `birth`

短いが、出生届・入院費・退院の段取りが同時に来る。書く人は父親や家族になることが多い。

| 種類 | 課題 |
|---|---|
| 手続き | 出生届の書き方と持ち物（出生証明書は産院が書く）。夜間・休日窓口。マイナンバー・住民票の反映まで時間がかかる |
| お金 | 退院時の精算（一時金を引いた額を払う）。クレジットカードが使えない施設。予約金の充当 |
| 病院 | 面会のルール。母子同室/別室。退院日 |

コラムの候補
18. **出生届の持ち物と、夜間・休日に出す方法（区ごとの窓口）** — birth／PR なし／出典: 各区の戸籍のページ
19. **退院の日の精算: いくら現金が要るか、カードは使えるか** — birth／PR なし／出典: 施設HP（一般論）＋ Navi の記録の集計

## 産後（〜1年）`postpartum`

期限の短い手続きが続き、その後は助成・健診・保育園。睡眠不足の中で読める短さが要る。

| 種類 | 課題 |
|---|---|
| 手続き | 児童手当（15日）、健康保険の加入（子の医療証に必要）、乳幼児医療証、出生通知票→訪問、1か月児健診、産婦健診、支援給付2回目、都の018サポート・赤ちゃんファースト、無痛助成（1年） |
| お金 | 出産手当金・育児休業給付金の入金時期（数か月後）。それまでの生活費。会社員の保険料免除 |
| 仕事 | 育休中の手続き（延長、保育園に入れなかったときの証明）。復帰の準備、保育園の申込み（産後すぐ始まる区もある） |
| 準備・買い物 | 産後の自分の回復用品、授乳関連、赤ちゃんの月齢ごとの買い足し |
| 病院 | 産婦健診・1か月児健診の受診票。予防接種の予定（医療の内容には触れない） |

コラムの候補
20. **産後の入金カレンダー: 一時金・出産手当金・育児休業給付金はいつ入るか** — postpartum／PR なし／出典: 協会けんぽ・ハローワーク
21. **保育園の申込みは産後すぐ始まる: 東京23区の一次申込みの時期** — postpartum／PR なし／出典: 各区の保育課（時期は毎年変わるので確認日を必ず）
22. **産後1年以内に申請できる助成の総まとめ（都・区）** — postpartum／PR なし／出典: 都・各区。Naviの「お金」へ
23. **産後1か月の買い足しリスト（出産前に買わなくてよかったもの）** — postpartum／PR あり
24. **父親がやる手続きチェックリスト（産後2週間版）** — postpartum／PR なし

## 書く順番の案

1. まず **PR なし** で信頼をつくる: 1（初期2週間）・12（産後の分担表）・20（入金カレンダー）・7（産休の計算）。Naviへの導線が太い。
2. 次に **PR あり** の準備系: 13（入院バッグに Amazon リンクを足す）・10（産前/産後の分け方）・16（最初の1か月）。
3. そのあと周期の穴を埋める（2・6・8・18・21）。

## コラムの生成のしかた（2026-09-23 の方針案）

- 下書きは Claude が書く。ただし **公開前に人が読む**。制度の数字は `sources` の URL を人が開いて確かめ、`verified_at` を入れる。
- 医療に踏み込みそうな段落は「産院に相談してください」で止める。書きたい内容が医療そのものなら、そのコラムは書かない。
- 各コラムの最後に Navi への導線（`/navi`）を置く。手続きの答えはコラムに書かず、Navi に任せる（データが更新されてもコラムが古くならない）。
- 英語版は、日本語版が固まってから（同じ数字・同じ出典）。
- 製品の選び方の基準はコラムの中に書く（例: 産院のリストにある品目・価格帯）。「効果」は書かない。
