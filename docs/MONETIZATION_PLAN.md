| 採る | このサイトでのやり方 |
|---|---|

## 2. このサイトの勝ち筋

1. **集客は制度データのページ（316枚）。** 区名×手続き名で来た人に、出産準備リストと選び方のコラムをつなぐ。
2. **収益は「出産準備リスト」（/junbi）と選び方のコラム。** 「出産準備 リスト」「入院準備 リスト」は検索の多い語。上位は大手の「◯選」型なので、「産院と区がくれるものは買わない」「区ごとの配布物」という切り口で差をつける。
3. **単価はサービス案件で上げる。** 物販だけでは月100万円に届かない（3章の計算）。

## 3. 月100万円の収益モデル（仮定）

単価は一般的な目安で、A8などの管理画面で必ず確かめる（運営者のアカウントに私は入れない）。

| 収益源 | 1件の目安 | 月の件数 | 月額 |
|---|---|---|---|
| 物販（Amazon・楽天。1件あたり約150円） | 約150円 | 600件 | 約9万円 |
| 0歳向けの知育・通信教材 | 2,000〜3,000円 | 40件 | 約10万円 |
| 写真スタジオの無料撮影・ニューボーンフォト | 2,000〜5,000円 | 30件 | 約9万円 |
| 産後の宅配食 | 1,500〜3,000円 | 30件 | 約6万円 |
| ベビー用品レンタル（ベッド・チャイルドシート） | 1,000〜3,000円 | 20件 | 約4万円 |
| 内祝い（カタログギフトなど） | 物販の料率 | — | 約5万円 |
| ウォーターサーバー【要判断】 | 8,000〜15,000円 | 15件 | 約15万円 |
| 保険の無料相談（FP）【要判断】 | 10,000〜20,000円 | 25件 | 約37万円 |
| 合計 | | | 約95万円 |

- 【要判断】の2つで全体の半分を占める。この2つ無しだと、同じ集客で月40〜50万円が目安。
- 必要な集客: 収益ページへの訪問 月3〜4万、サイト全体で月10〜15万の訪問（成約率0.5〜1%の仮定）。
- 期間: 新しいドメインのため、18〜24か月が現実的な目安。

## 5. 今回作ったもの（2026-10-25）

- 出産準備リスト `/junbi`: 時期ごとにチェックでき（端末に保存）、予定日が入っていれば「いまの時期」を目立たせる。各品目に商品ボックス。トップ・区の一覧・今週やること・フッターから導線。
- 商品ボックス: `content/shop/products.yaml` の商品を、コラムでは `[[product:<id>]]` の1行で出す。Amazon・楽天（・A8）のボタン、小さなPRの印。価格は出さない（Amazonの規約）。
- PR表記: 記事の先頭は1行の小さな表示、くわしい文言と規約の文言は記事の最後。
- 本文: 行間2・字間・段落の間を広げた。

## 6. 運営者の判断が要ること

1. **保険の無料相談とウォーターサーバーを扱うか。** 扱うなら、保険は「相談サービスの紹介」だけにし、特定の保険商品の良し悪しは書かない（保険業法の募集行為にあたらないように）。ウォーターサーバーは「ミルク作りに必須」のような表現をしない。
2. **A8で申請する案件。** 知育（0歳）・写真スタジオ・宅配食・ベビー用品レンタル・内祝い（＋判断次第で保険相談・ウォーターサーバー）。提携できたら広告リンクのURLを送ってもらえれば、`products.yaml` の `a8_url` に入れて表示する。
3. **予算。** 体験談・写真の外注、SNS の広告を使うか。
