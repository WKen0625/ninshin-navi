# 産後の仕事探しと保育園、どちらが先？求職中の申し込み・90日の認定・在宅の求人の探し方【2026年版】

「保育園に入れないと働けない、でも働いていないと保育園に入れない……」と悩んでしまいますよね。実は、**仕事を探している途中でも、保育園に申し込めます**。この記事では、国の決まりと、保育園と仕事探しを同時に進める順番をまとめました。

:::summary この記事でわかること
- 求職活動が「保育の必要性」の理由になること
- 求職活動での認定は90日まで
- 在宅の仕事を選ぶときに確かめること
:::

:::point 先に結論
- **求職中でも申し込める**（子ども・子育て支援法施行規則）。
- 求職活動での認定は**90日を限度に区が決める**。申し込みの前から求人を見ておく。
- 在宅の仕事は、**保育園に出す書類がそろうか**を応募の前に確かめる。
:::

## 求職中でも、保育園に申し込める？

:::talk
Q: 仕事が決まっていないと、保育園に申し込めないのでは？
A: 認可保育園に入るには、区から「保育の必要性」の認定を受けます。その理由の中に、求職活動が入っています。仕事を辞めて出産した人や、来日して日本での仕事をこれから探す人も、求職活動で申し込めます。
:::

子ども・子育て支援法施行規則の第1条の5に並んでいる、「保育の必要性」の理由です。両親のどちらも、いずれかに当てはまることが条件です。

| 理由 | 内容 |
|---|---|
| 就労 | 1か月に、区が決める時間以上働いている |
| 妊娠・出産 | 妊娠中、または出産して間がない |
| 病気・障害 | 病気・けが・障害がある |
| 介護・看護 | 同居の家族を介護・看護している |
| 求職活動 | 求職活動（起業の準備を含む）を続けている |
| 就学 | 学校に通っている・職業訓練を受けている |

## 求職活動の認定は「90日まで」

同じ施行規則で、求職活動を理由にした認定の有効期間は、認定の始まりの日から「九十日を限度として市町村が定める期間」を過ぎる日の月末までとされています。区によって、期間の長さや延ばせるかどうかが違います。

:::caution 期間のうちに仕事が決まらないと
保育園を続けられなくなることがあります。入園が決まってから探し始めるのではなく、申し込みの前から求人を見ておくと、期間を使い切らずに済みます。
:::

入園の選考は、区の「利用調整基準」の点数で決まります。区の保育課のページにある基準表で、求職中の点数と、働き方ごとの点数を先に確かめます。

## 在宅の仕事を選ぶときに確かめること

:::check 応募の前のチェックリスト
- 働く時間: 区が決める時間（1か月あたり）以上働く予定か
- 証明の書類: 雇われて在宅で働くなら、勤務先が就労証明書を書く
- 業務委託（雇用でない在宅の仕事）は、働いていることを示す書類が区ごとに違う。区の保育課に何を出せばよいか聞いておく
- 求人の「雇用/契約形態」を見て、保育園に出す書類がそろうか
:::

## 求人の探し方の例: ママワークス

2026年10月25日に公式ページで確かめた内容です。

| 項目 | 公式ページの内容 |
|---|---|
| 探し方 | 在宅・時短勤務などの求人を「働き方」「雇用/契約形態」「職種」「都道府県」の4つから探せる。「こだわり条件」で絞り込める |
| 応募 | 無料の会員登録が要る。15個のスキルの選択肢から1つ以上をチェックする |
| 相談 | 経歴を入れた会員に、運営事務局から電話でキャリアカウンセリングをすることがある（全員ではない） |
| 運営 | 株式会社アイドマ・ホールディングス |

:::good こんな人に合います
- 子どもが寝ている時間や、保育園に預けている時間に働きたい
- 在宅や時短の求人から探したい
:::

## よくある質問

:::talk
Q: 申し込みの締切はいつ？
A: 区によって違います。4月入園は、前の年の秋から冬に一次申込みを締め切る区が多いです。[保育園の申込みの時期の記事](/articles/nursery-application-timing)にまとめています。
Q: 外国籍の家族も同じ？
A: 「保育の必要性」の決まりは同じです。口座や在留カードの準備も合わせて進めておくと、入園後の手続きが楽です。
:::
