# 抱っこ紐はどれを選ぶ？3つの型の違いと「生後○か月から」の見方【2026年版】

抱っこ紐って、種類が多くて迷いますよね。しっかりした腰ベルト型、軽い前抱き型、布を巻くラップ型……。どれを選ぶときも、最初に見るのは製品に書かれた**「生後○か月から」**の表示です。この記事では、3つの型の違いを絵と表でひと目で比べられるようにまとめました。

:::summary この記事でわかること
- 抱っこ紐の3つの型と、それぞれ合う人
- 「生後○か月から」の表示が、何で決まっているか
- 転落を防ぐ4つの使い方（公的機関の注意から）
:::

:::point 先に結論
- 1本で長く使うなら**腰ベルト型**、新生児のころを身軽にするなら**軽い前抱き型**、家の中や近所なら**ラップ型**。
- どの型でも、新生児から使うときは**表示と付属品（頭当て・インサート）**を確かめます。
:::

:::memo この記事の前提
この記事は、商品を使ったレビューではありません。メーカーの公表値と、公的機関の情報をもとに、比べやすく並べています。数字には出典と確認日を添えていて、出典の一覧は記事の最後にあります。
:::

## 抱っこ紐は、いつから要る？

:::talk
Q: 退院の日から抱っこ紐って要るの？
A: 退院の日は、車ならチャイルドシートで帰るので、抱っこ紐の出番はその先です。最初に使うのは、生後1か月ごろの健診や、区役所の手続きのことが多いです。
Q: それなら、産後に買えばいい？
A: 産後は試着に行きにくいので、妊娠後期のうちに、使う人が実際に着けてみて決めておくと安心です。
:::

## 3つの型を、ひと目で比べる

[[compare:carrier-ergo,carrier-mini,carrier-konny]]

### 目的別の早見表

| 重視すること | 合う型 | 見る項目 |
| --- | --- | --- |
| 1本で長く使いたい | 腰ベルト型 | 対象体重の上限・使える時期 |
| おんぶもしたい | 腰ベルト型 | 抱き方 |
| 新生児のころの着け外しを楽に | 軽い前抱き型 | 本体の重さ・着け方 |
| 家の中・近所で手軽に | ラップ型 | 本体の重さ・たたんだ大きさ |

### 腰ベルト型（1本で長く使う）

肩と腰の2か所でささえる型です。対面・前向き・腰抱き・おんぶと抱き方を変えられて、対象体重の上限が大きいのが特徴です。

:::good
- 1本で2〜3歳ごろまで使いたい
- おんぶもしたい
- パパとママで共有したい（ベルトを調節して使う）
:::

:::memo 購入前に確かめたいところ
- 本体の重さは、公式サイトで確かめる
- 新生児から使う条件（対象体重は3.2kgから）と、付属品の要不要を説明書で確かめる
- 日本正規品かどうか（保証の対象になるか）
:::

[[product:carrier-ergo]]

### 軽い前抱き型（新生児のころを身軽に）

本体が軽く、着け外しが簡単な型です。生後すぐから対面で使え、1歳ごろまでが対象のものが多いです。

:::good
- 新生児のうちの、短い外出が多い
- 着け外しを手早く済ませたい
:::

:::bad
- 2歳ごろまで1本で済ませたい（対象体重の上限が小さめです）
:::

:::memo 購入前に確かめたいところ
- 対象体重は3.2〜11kg（1歳ごろまで）
- 前向き抱きは5か月から
:::

[[product:carrier-mini]]

### ラップ型（家の中・近所に）

布を体に巻く型です。軽く、たたむと小さくなります。おんぶや前向き抱きはできません。

:::good
- 家の中での抱っこや、近所の買い物が中心
- バッグに入れて持ち歩きたい
:::

:::bad
- 長い時間の外出や、重くなってからも使いたい
- SGマークの製品から選びたい（この例の商品はSGマークの製品ではありません）
:::

:::memo 購入前に確かめたいところ
- サイズ調節式（XS〜XL）なので、使う人の体に合うかを確かめる
- 抱き方は対面だけ
- メーカーは、海外の安全基準（ASTMなど）の認証を表示しています
:::

## 「生後○か月から」は、SG基準で決まっている

製品安全協会の「抱っこひものSG基準」では、使える月齢が型ごとに決められていて、製品には「生後○か月以降」と表示することになっています。

| 型 | 使える月齢（SG基準） |
|---|---|
| 縦抱っこ式（立てて抱く） | 4か月〜24か月。頭当てがあり対面で抱くものは生後1か月から |
| 横抱っこ式（寝かせて抱く） | 0か月〜6か月（腰がすわる前まで） |
| 背負い式（おんぶ） | 4か月〜36か月（首がすわってから） |
| 腰抱っこ式 | 7か月〜36か月（背当てがあれば4か月から） |

基準では、首すわりの目安を「早い子で約3か月、標準で生後4か月を過ぎてから」としています。成長には個人差があるので、月齢は表示の目安です。赤ちゃんの様子は健診で確かめてください。

:::memo SGマークがない製品は？
海外の基準で作られた製品には、SGマークがないこともあります。その場合も、製品に書かれた対象月齢と対象体重を見て選びます。
:::

## 買う前に見る5つ

:::check 買う前のチェックリスト
- 対象月齢: 新生児から使うなら、表示と付属品（頭当て・インサート）
- 対象体重: 何kgまで使えるか
- 抱き方: 対面・前向き・おんぶのどれが要るか
- 本体の重さ: 毎日の着け外しの負担
- 洗えるか: 洗濯機で洗えるか
:::

## 転落を防ぐ使い方（公的機関の注意）

国民生活センターが2025年3月に公表した資料では、医療機関から集めた事故情報で、2019年度からの5年10か月に抱っこ紐の使用中の事故が176件、うち子どもの落下が138件ありました。落下の約4件に1件が、骨折または頭蓋内損傷です。消費者庁と東京都の注意喚起でも、事故が起きる場面はほぼ同じです。

:::caution 毎回、この4つ
- 乗せ降ろしは、椅子に座るなど低い姿勢で
- 前にかがまない。物を拾うときは、手で子どもを支えて膝を曲げてしゃがむ
- ひもは毎回調整する（服の厚みで緩み、緩いと脇からすり抜ける）
- 留め具（バックル）が留まっているかを毎回確かめる
:::

## よくある質問

:::talk
Q: 抱っこ紐は2本要る？
A: 1本で足ります。外出が多い家庭や、使う人が2人いる家庭は、新生児のころは軽い前抱き型、そのあとは腰ベルト型と分ける方法もあります。
Q: 前向き抱きはいつから？
A: 例に挙げた腰ベルト型と前抱き型は、どちらも「5か月から」と表示されています。製品の表示に従ってください。
Q: 新生児に使うとき、インサートは要る？
A: 製品によって違います。新生児から使える条件（インサートの要不要・対象体重）は、製品の説明書で確かめます。
:::

:::summary まとめ
- まず「生後○か月から」と対象体重を見る
- 長く1本なら腰ベルト型、新生児のころを身軽になら前抱き型、家の中ならラップ型
- 使うときは、低い姿勢・かがまない・毎回調整・留め具の確認
